Phantom Chess — Design Ideas

Version: 0.2
Status: Initial UI design planning
Project: Phantom Chess

1. Design Vision

Phantom Chess aims to provide a mysterious, elegant, modern, and user-friendly chess experience.

The interface should combine an atmospheric visual identity with a clear and accessible layout.

2. Visual Direction

- Primary colours: Black and deep purple.
- Accent colour: Lavender.
- Overall appearance: Dark, mysterious, elegant.
- Interface inspiration: The approachable and user-friendly layout of Duolingo Chess, while maintaining an original Phantom Chess identity.

3. Welcome Screen

The Welcome Screen is the first screen a new player encounters.

Elements

- Phantom Chess logo.
- Game name: PHANTOM CHESS.
- Home Screen button.
- How to Play button.
- Checkbox: "Skip the Welcome Screen next time".

Button Functions

Home Screen

- Takes the player directly to the Main Home Screen.

How to Play

- Opens the How to Play menu.

Skip Welcome Screen

- The checkbox allows players to skip the Welcome Screen on future launches.
- When enabled, the game opens directly to the Main Home Screen.
- How to Play remains accessible from the Main Home Screen.
- Players can change this preference through Settings.

4. How to Play Menu

The How to Play menu contains two options.

4.1 Rule Book

- Provides written explanations of Phantom Chess rules.
- Initially focuses on text-based explanations.
- Future updates may introduce illustrations, diagrams, and visual examples.

4.2 Interactive Chess Game

- Provides a simplified playable demonstration of Phantom Chess.
- Demonstrates the game's rules and unique mechanics.
- Is intended for learning, not competitive gameplay.
- Players can leave the tutorial at any point.
- Leaving returns the player to the How to Play menu.
- Every new tutorial session starts from the beginning.
- Tutorial progress is not saved.

5. Screen Navigation

The initial navigation structure is:

1. Welcome Screen
2. Main Home Screen
3. How to Play Menu
4. Rule Book
5. Interactive Chess Tutorial

The Main Home Screen and How to Play Menu are separate destinations.
