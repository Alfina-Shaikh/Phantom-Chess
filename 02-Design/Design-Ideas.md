Phantom Chess — Design Ideas

Version: 0.2
Status: Initial UI design planning
Project: Phantom Chess

1. Design Vision

Phantom Chess aims to provide a mysterious, elegant, modern, and user-friendly chess experience.

The interface should combine an atmospheric visual identity with a clear and accessible layout.

2. Visual Direction

- Primary colours: Black and deep purple.
- Accent colour: Lavender.
- Overall appearance: Dark, mysterious, elegant.
- Interface inspiration: The approachable and user-friendly layout of Duolingo Chess, while maintaining an original Phantom Chess identity.

3. Welcome Screen

The Welcome Screen is the first screen a new player encounters.

Elements

- Phantom Chess logo.
- Game name: PHANTOM CHESS.
- Home Screen button.
- How to Play button.
- Checkbox: "Skip the Welcome Screen next time".

Button Functions

Home Screen

- Takes the player directly to the Main Home Screen.

How to Play

- Opens the How to Play menu.

Skip Welcome Screen

- The checkbox allows players to skip the Welcome Screen on future launches.
- When enabled, the game opens directly to the Main Home Screen.
- How to Play remains accessible from the Main Home Screen.
- Players can change this preference through Settings.

4. How to Play Menu

The How to Play menu contains two options.

4.1 Rule Book

- Provides written explanations of Phantom Chess rules.
- Initially focuses on text-based explanations.
- Future updates may introduce illustrations, diagrams, and visual examples.

4.2 Interactive Chess Game

- Provides a simplified playable demonstration of Phantom Chess.
- Demonstrates the game's rules and unique mechanics.
- Is intended for learning, not competitive gameplay.
- Players can leave the tutorial at any point.
- Leaving returns the player to the How to Play menu.
- Every new tutorial session starts from the beginning.
- Tutorial progress is not saved.

5. Screen Navigation

The initial navigation structure is:

1. Welcome Screen
2. Main Home Screen
3. How to Play Menu
4. Rule Book
5. Interactive Chess Tutorial

The Main Home Screen and How to Play Menu are separate destinations.

6. Main Home Screen

The Main Home Screen is the primary navigation dashboard of Phantom Chess.

6.1 Layout

The proposed layout contains:

- Game logo in the top-left corner.
- Profile access in the top-right corner.
- Game name displayed below the top section.
- Six main navigation buttons arranged in two columns.

6.2 Profile

Opens the player's profile, including their name and profile-related settings.

6.3 Play

Opens a submenu containing:

- Play with Bot.
- Play with Friend.
- Random Player (planned for a future multiplayer update).

6.4 History

Displays previous matches, including their progression from beginning to end.

Future functionality may include reviewing private notes associated with previous matches.

6.5 Formation

Opens a formation management screen containing three formation slots.

- All three slots are empty initially.
- Players can add formations to empty slots.
- Existing formations can be edited.
- Players can delete saved formations.
- Each slot stores a player's custom formation.

6.6 Preferences

Provides customization options, including:

- Game themes.
- Colour schemes.
- Hidden identity visuals.

Additional customization options may be introduced in future updates.

6.7 How to Play

Opens the previously defined How to Play menu, containing:

- Rule Book.
- Interactive Chess Game.

6.8 Credits & Contact

Provides information about the project, including:

- About Phantom Chess.
- Developer credits.
- Open-source libraries and asset acknowledgements.
- Contact information.
- Potential feedback and problem-reporting options.
